## Наблюдения

1. **Фильтр модели не мешает.** Ни одного `finish_reason: content_filter`, поле `diagnostics.filtered_out` пустое во всех строках. Запросы со ст. 63 УК РФ в контексте (Q05, Q06, Q11), которые в gigachat-1 отклонял фильтр GigaChat, получили верные ответы.
2. **Проверка меток не отклонила ни одного ответа** (`diagnostics.rejection` пуст): каждый абзац пояснения содержит метку статьи из контекста. Все отказы — решения самой модели (`model_refusal`).
3. **Отказы модели при неполном контексте** (Q04, Q08): модель отказывается целиком, когда есть сведения только по части вопроса. Для оценки по эталону это не меняет результат, но пользователю частичный ответ был бы полезнее. Вопрос к промпту (`prompts.ts`, зона Грачева Константина) и к сценариям (Корегин Илья).
4. **Поиск — главная оставшаяся причина ошибок** (Q04, Q08): BM25 сравнивает слова буквально и пропускает статьи с другими формами слов. Нормализация словоформ — предложение для поиска (зона Грачева Константина).
5. **Неполнота ответов** (Q02, Q10): модель отвечает на буквальный вопрос и опускает части статьи из контекста, которые есть в эталоне. Можно попросить в промпте перечислять все условия и исключения из относящихся к вопросу частей статей; эффект проверяется следующим прогоном.
